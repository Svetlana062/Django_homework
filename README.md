# 21.2 Основы верстки (проект Django)

## Описание
Создан проект базовой реализации интернет-магазина, который будет дорабатываться на каждом уроке в течение всего курса.

## Требования к окружению
Python 3.13+

## Установка
* Клонируйте репозиторий:
```
git clone https://github.com/Svetlana062/Django_homework.git
```
* Установите зависимости:
```
pip install -r requirements.txt
```
* Войдите в виртуальное окружение:
```
poetry shell
```

## Структура проекта
Данный проект содержит три приложения.

### Приложение под названием "catalog":
* содержит десять HTML-шаблонов: для домашней страницы (home.html), для страницы с контактной информацией (contacts.html),
шаблон для успешной отправки данных (contact_success.html) и шаблоны для просмотра и редактирования продуктов,
а так же базовый шаблон и шаблон основного меню;
* модели Product и Category с базовыми настройками (catalog/models.py);
* файлы с миграциями (catalog/migrations/);
* фикстуры для моделей Category и Product (category_fixture.json);
* созданы кастомные команды для добавления тестовых продуктов (catalog\management\commands\add_test_products.py)
и добавления группы Модератор продуктов (catalog\management\commands\create_moderator_group.py).

### Приложение под названием "blog":
* содержит четыре HTML-шаблона: для создания, просмотра, редактирования и удаления статей;
* модель BlogPost, которая описывает структуру данных для хранения информации о блоговых записях в базе данных;
* файлы с миграциями (blog\migrations).

### Приложение под названием "accounts":
* содержит четыре HTML-шаблона: для регистрации, авторизации, редактирования и просмотра профиля;
* модель CustomUser: расширенная модель пользователя Django, основанная на встроенной модели AbstractUser;
* файлы с миграциями (accounts/migrations/);
* файл для создания администратора (accounts\management\commands\csu.py).
